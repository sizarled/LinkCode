# LinkCode — تطبيق أندرويد

هذا المجلد يحوّل موقع LinkCode إلى تطبيق أندرويد (APK) باستخدام WebView.

## كيف يعمل
- ملفات الموقع في جذر المستودع (`*.html` و `assets/` و `unlock/`) تُنسخ تلقائياً إلى داخل التطبيق عند البناء.
- المستودع هو المصدر الوحيد: عدّل الموقع، ثم أعد بناء التطبيق.
- الروابط القصيرة `/123456` تفتح صفحة الفك مباشرة، وروابط `https://l2c.space/...` تفتح داخل التطبيق.
- روابط المواقع الخارجية (صفحات الوجهة) تُفتح في المتصفح.
- الاتصال بقاعدة بيانات Supabase يتم عبر الإنترنت كما في الموقع.

## البناء عبر GitHub Actions (الطريقة الموصى بها)
1. ادفع التغييرات إلى الفرع `arena/c5733580-linkcode` (يبدأ البناء تلقائياً)، أو شغّل الworkflow يدوياً من تبويب **Actions** → **Build Android APK** → **Run workflow**.
2. بعد اكتمال البناء، حمّل الملف `LinkCode-debug-apk` من قسم **Artifacts** في صفحة التشغيل.
3. انقل ملف `app-debug.apk` إلى الهاتف وثبّته (يجب السماح بالتثبيت من مصادر غير معروفة).

## البناء محلياً
يلزم: JDK 17 و Android SDK (platform 35، build-tools 35.0.0) و Gradle 8.9.
```bash
cd android
gradle assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## ملاحظات
- المعرّف الحالي للتطبيق: `com.linkcode.app` (يمكن تغييره في `app/build.gradle`).
- الناتج نسخة `debug` موقّعة تلقائياً للتجربة. للنشر على Google Play تحتاج إلى مفتاح توقيع خاص (keystore) وبناء `release` أو `.aab`.
- عند تعديل الموقع يجب إعادة بناء التطبيق لتظهر التغييرات داخله.
